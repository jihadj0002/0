## 📝 How to Use

When you talk to a new prospect:
1. Add to **Active Conversations** table
2. Log the conversation in **Contact Log**
3. Update **Pipeline** count
4. Set **Next Action** with date

When a prospect responds:
1. Move to appropriate stage
2. Log response in Contact Log
3. Schedule next action

When a prospect converts:
1. Move to ✅ Converted
2. Create client file in `00_CONTEXT/client-case-studies/`
3. Update GROWTH.md metrics
